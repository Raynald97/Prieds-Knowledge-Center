Graph Editor
Drag titik biru untuk connect

Seperti Miro: drag node untuk memindahkan posisi. Untuk membuat connection, tarik titik biru di sisi node lalu drop ke node / titik biru tujuan. Drag langsung garis untuk membuat atau menggeser bend. Klik bend lalu tekan Delete atau gunakan tombol Delete Bend untuk menghapus sudut yang tidak diperlukan. Klik garis untuk membuka toolbar Label / Bend / Auto Route / Delete Line. Semua garis tetap orthogonal 90°.

Advanced Connections Fallback untuk edit Source, Target, Port, label, dan route secara manual.
